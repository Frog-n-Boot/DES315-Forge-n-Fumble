# Source backup for Frog 'n' Boot game: Forged 'n' Fumble 

Github Version has no final assets, only programmer assets (temps). This repo's job is to simply track any major releases of the project as a backup to perforce. 4 Main branches exists. Release, Demo, Alpha and Beta.

The game is only a demo and should be treated as such. Future works may continue but are not garenteed.
